# もちっと！ハロウィンおかしキャッチ

本作は『トリッカル・もちもちほっぺ大作戦』の **非公式ファンゲーム** です。公式とは関係ありません。原作に関する権利は各権利者に帰属します。

GiGO コラボ「トリッカル or トリート!!」の仮装をした 5 人で、おばけの国に降ってくるお菓子をキャッチする 60 秒のスコアアタック。

- 左右に動いて、落ちてくるお菓子を頭でほおばる。1.5 秒以内に取り続けると **れんぞくキャッチ**（10 個ごとに倍率 +0.1、最大 ×2.0）
- **ホバギ**（かぼちゃ）に当たると −20 点・ひるむ・れんぞくが切れる。落ちる先には影が出る
- ホバギをよけて地面に落とすと、丘のスピッキーが泣いて **スピキ** になる。泣いている間にタップでなぐさめると「チョワヨ！」で、泣いた分だけお菓子の **おかえし**（ほっぺを大きく引っぱってから離すと +1 個）。もう 1 個泣かせてから、なぐさめるほうがおかえしは多い
- **モカロン** 5 個で **フィーバー**（6 秒）。シューカロン（+50）の大雨
- 残り 15 秒で **ラストスパート**（お菓子が増える・BGM が速くなる）
- キャラごとのベストスコアとランク（SS / S / A / B / C）、累計のおかしで称号（タイトルの「きろく」で一覧・つぎの称号までの数が見られる）
- **ミッション**: 小さな目標が 3 つずつ出て、クリアすると次が出る（全 44 こ）。ごほうびのおかしで称号も近くなる。タイトルのミッションを押すと一覧
- **れんしゅう**: はじめて遊ぶ時だけ、実際に動かして覚える短いチュートリアル（うごく → キャッチ → よける → スピキをなぐさめる）。スマホはタップ、PC は Space キーをうながす。ポーズからとばせて、あそびかたからもう一度できる
- **コース**: ふつう / **今夜のおかし**（日替わりのルール。同じ日はみんな同じルール） / **まよなか**（速くてホバギが多い。ふつうでランク A を取ると解放）
- タイトル・キャラえらび・リザルトのキャラも、ほっぺを引っぱれる（[エシュールのパン屋さん](https://github.com/saba383810/trickcal-ashur-bakery) のもちほっぺの移植）。しつこく引っぱると、キャラがひとこと。回数は「きろく」に残る
- **キャラのひとこと**: 遊んでいる途中（フィーバー・れんぞく・ホバギに当たった時など）と、結果のセリフ。結果のセリフは遊び方で変わり（5 人 × 12 種）、見つけたものは「セリフずかん」に残る。セリフは `src/config/lines.ts`

| キャラ | 仮装 | とくせい |
|---|---|---|
| コミー | 死神 | 鎌でキャッチのはばがとても広い。足はおそい |
| エルフィン | 魔女 | いちばん速いけど、すべって止まりにくい。スターキャンディが +30 点 |
| バター | ミイラ | ホバギに当たっても ひるまず、れんぞくも切れない（減点は半分）。はじめての人に |
| ヨミ | おばけ | モカロン 4 個でフィーバー |
| ジョアン | 吸血鬼 | ホバギを吸ってフィーバーゲージにする（減点なし）。キャッチのはばは せまい |

設計の詳細（企画案からのブラッシュアップを含む）は [docs/design.md](docs/design.md)。

## 操作

| 操作 | タッチ | マウス | キーボード |
|---|---|---|---|
| 左右に動く | 画面のどこでもドラッグ（ずらした分だけ動く） | カーソルを追いかける | `←` `→` / `A` `D` |
| スピキをなぐさめる | スピキをタップ（引っぱって離すと +1） | 同じ | `↑` / `W` / `Space` |
| ポーズ | ポーズボタン | 同じ | `Esc` / `P` |

スマホの縦持ち／横持ち、PC のどれでも、画面の縦横比に合わせて表示します。タブを離れると自動でポーズします。

## 開発

```sh
npm ci
npm run dev      # http://localhost:5173/
npm test         # ロジックの単体テスト（vitest）
npm run sim      # ボットによるバランス確認（キャラ × 腕前ごとのスコア分布・ランク分布・ミッションのクリア率。RUNS=120 で回数、RULE=night などでコースのルール）
npm run build    # 型チェック + 本番ビルド（dist/）
```

- 開発用ページ: `/preview.html`（キャラ・表情・お菓子の一覧）、`/art.html`（掲載用の絵。`?kind=thumb` で 800×515、`?kind=og` で 1200×630）。本番ビルドには含まれません。
- 開発サーバーでは `?dev=select|howto|settings|records|pause|play|result` で各画面へ直接飛べます（`&char=elfin` キャラ、`&course=daily|night` コース、`&t=40` 経過秒、`&fever` フィーバー中、`&cry=2` スピキが泣いている、`&bot` ボットが操作）。コンソールから `app` で状態を触れます（本番ビルドでは無効）。
- 絵はすべて Canvas 2D のコード描画（ほっぺの変形だけ WebGL2。使えない環境では変形なしで描画）、音はすべて WebAudio の合成です（素材ファイルなし）。
- ゲームの数値は `src/config/balance.ts` と `src/config/characters.ts`、コースのルールは `src/config/rules.ts`、ミッションは `src/config/missions.ts` に集めてあります。

## sabanogames への組み込み

[sabanogames](https://github.com/saba383810/sabanogames) の「あそび場」に、エシュールのパン屋さんと同じ submodule 方式で載せる想定です。

- submodule: `entertainments/trickcal-or-treat-2026`（このリポジトリ）
- 公開 URL: `https://sabanogames.com/entertainments/trickcal-or-treat-2026/`（CI が作るフレームページ。本体は `app/` 配下）
- CI は `npm ci && npm run build -- --base=/entertainments/trickcal-or-treat-2026/app/` でビルドする
- 一覧のエントリは sabanogames の `site/src/data/entertainments.ts`、サムネイルは `docs/thumbnail.png` のコピー
  （`site/public/images/entertainments/trickcal-or-treat-2026.png`）。X などのリンクの絵は `docs/og.png` のコピー
  （`trickcal-or-treat-2026-og.png`。エントリの `ogImage`）
